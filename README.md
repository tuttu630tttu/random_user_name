# tuttutu256のランダムユーザーID生成器

ユーザーIDがコンフリクトして使えない場合、または新しいものにしたいけれどすぐには思いつかない、そんなときに私のアイデンティティを保ちつつ新しいユーザーIDを生成してくれる C++ ソースコードを組みました。
便利な道具ではなく、あくまでも娯楽用です。

## 使い方

C++11 以降に対応したコンパイラと `make` があれば動きます。追加のライブラリは不要です。

```sh
make
./username
```

実行するたびに、ユーザーIDの候補を1つ表示します。

```text
UserNameIs...
tuttutu256
```

上の出力は一例です。同じIDが出ることもあります。

`t` の最大連続数は、引数で指定できます。

```sh
./username 2
```

この場合、末尾も含めて `t` は最大2文字まで連続します。1以上の整数を指定してください。
`1` を指定すると英字部分は交互に並ぶため、長さは6・8・10文字のいずれかになります。
英字部分は最大10文字なので、大きな値を指定しても名前自体が長くなるわけではありません。
`./username --help` で引数の説明を表示できます。

末尾の数字がいらない場合は `--no-number` を付けてください。`t` の最大連続数とも組み合わせられます。引数の順番はどちらでも構いません。

```sh
./username --no-number
./username 2 --no-number
```

`make` を使わない場合は、直接コンパイルしてください。

```sh
c++ -std=c++11 -O2 -Wall -Wextra -Wpedantic username.cpp -o username
./username
```

生成した実行ファイルは `make clean` で削除できます。

## 生成ルール

私らしさを保つために、使う文字にはかなり偏りがあります。

- 英字部分は5〜10文字で、最初の文字は `t` です。
- 途中に使う文字は `t` と `u` で、`u` は `t` の直後にだけ現れます。
- 英字部分の最後は必ず `tu` または `ty` になります。
- 末尾に `000`〜`999` の数字を3桁付けます（`--no-number` で省略できます）。

全体では8〜13文字、数字なしでは5〜10文字になります。引数なしの場合、途中で `t` が3文字続いたら次は `u` になりますが、末尾の `tu` / `ty` を優先するため、最後だけ `t` が4文字続くことがあります。引数で上限を指定した場合は、末尾もその上限を守ります。

生成したIDが各サービスで空いているかどうかは、自分で確認してください。

> 末尾が tty になると、まるでターミナルの tty のようで激アツです。
